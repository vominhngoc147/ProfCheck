# Đợt 5 Implementation Plan (P-forum Reddit-like + reup review)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Forum kiểu Reddit (tag → topic → post → nested comment, vote ±1) + reup review thành post / reup vào topic, tôn trọng cờ `allow_forum_reup` 2 lớp (D20).

**Architecture:** 2 migration (`0021` schema+RLS+triggers, `0022` reup guard + hot-score view), actions `forum.ts`, 4 routes `/forum`, `/forum/new`, `/forum/[topic]`, `/forum/post/[id]`, nút reup trên ReviewCard.

**Tech Stack:** Next.js 16 App Router, Supabase Postgres + RLS, TypeScript, Tailwind v4.

**Spec:** `docs/superpowers/specs/2026-10-03-profcheck-upgrade-design.md` (mục Đợt 5)

## Global Constraints
- Migration mới = thêm file SQL đánh số tăng dần vào `supabase/migrations/`, KHÔNG sửa file đã chạy.
- Code tiếng Anh, UI copy qua dictionary i18n (`src/i18n/dictionaries/vi.ts`, `en.ts`).
- Không commit secret; `.env*` đã trong `.gitignore`.
- `npm run build` + `eslint` sạch + smoke test route mới bằng server thật trước khi commit.

## Quy ước đã chốt
- Tag do admin tạo + user verified đề xuất (insert verified, hiển thị sau khi tạo, admin dọn sau).
- Topic thuộc 0-n tag (join table), post thuộc 0-1 topic (null = tổng hợp).
- Vote ±1 cả post lẫn comment, 1 user 1 vote/target (bấm lại = gỡ, đổi chiều = chuyển).
- Comment lồng tối đa 3 cấp (action chặn sâu hơn), cascade xóa.
- Reup = tạo post link về review gốc + snapshot nội dung (phòng khi review bị xóa); trigger DB chặn khi review chưa approved hoặc 1 trong 2 cờ allow = false.
- Sort feed: hot (score/giảm dần theo giờ, tính JS trên 100 post mới nhất), new, top. Verified mới được đăng/vote/comment.
